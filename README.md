# 摸鱼小狐

下班倒计时 + 实时收入的桌面小工具。一只躺在木筏上钓鱼的小狐狸陪你熬到下班。

支持 Windows / macOS，基于 Electron 45。当前版本 **v1.2.0**。

项目位置：`~/Projects/MoyuFox`，发布好的安装包在 `releases/v<版本>/`。

## 功能

- **下班倒计时**：根据上下班时间实时倒计时，并显示今日工作进度。
- **今日已赚**：按秒累计今天的收入，可选扣除午休时间；同时显示本月累计、日薪、时薪、距离休息和距离发薪的天数。
- **专注识别（v1.2.0）**：分辨你是在用工作软件认真工作，还是在摸鱼，并统计专注时长，详见下文。
- **状态自动切换**：上班前、工作中、午休、已下班、休息日五种状态，文案和小狐狸的表情会随之变化。
- **时段配色**：场景按清晨、白天、黄昏、夜晚自动变色，夜里会出现星星和月亮。
- **互动**：点小狐狸会冒爱心、说话；点水面会有鱼跳出来。
- **自定义背景（v1.1.0）**：主界面和桌面小组件都能换成自己的图片、GIF 动图或视频，详见下文。
- **桌面小组件**：可拖动、可选择是否置顶、有四档大小；双击打开主界面，右键打开菜单。
- **菜单栏 / 托盘**：mac 菜单栏直接显示倒计时；Windows 托盘的悬停提示显示当前状态。
- **提醒**：上班、下班前 10 分钟、下班时发系统通知。
- **休息制度**：双休、单休、大小周、自定义，另外可以按日期单独标记放假或补班。
- **计薪天数**：21.75 天（法定）、当月实际工作日、自定义三种。
- 支持开机自启；关闭主窗口后程序继续在托盘运行。

## 专注识别

在右侧面板切到「专注」，打开「识别工作 / 摸鱼」：

| 状态 | 什么时候算 |
| --- | --- |
| 专注 | 工作时间内，**前台**正在用的是工作软件 |
| 摸鱼 | 工作时间内，前台是其它软件（后台开着的软件不算） |
| 离开 | 键盘鼠标超过设定时间没动（默认 5 分钟），或锁屏 |
| 加班 | 可选：下班后 / 休息日用工作软件，单独计入 |

- **设置工作软件**：开启后正常用一会儿电脑，「今天用过的软件」里会列出来，点「设为工作」即可；也可以直接从电脑里选（mac 选「应用程序」里的 app，Windows 选 .exe）。
- **统计内容**：今日专注 / 摸鱼 / 离开时长、摸鱼期间赚的钱、专注率、每个软件的使用时长、近 7 天趋势。午休不计。
- **显示位置**：主界面、桌面小组件、托盘可以分别开关；全部关掉也会照常在后台统计。
- **隐私**：只记录软件名称和使用时长，不截图、不记录窗口内容和网址；数据只保存在本机的 `focus-stats.json`，保留最近 120 天。
- **实现方式**：mac 用系统自带的 `lsappinfo` 读取前台应用，不需要申请任何权限；Windows 用一个隐藏的 PowerShell 进程读取前台窗口所属的程序。都不需要额外安装东西。

## 自定义背景

在右侧面板切到「外观」：

| 项目 | 说明 |
| --- | --- |
| 支持格式 | 图片 PNG / JPG / WebP / BMP，GIF 动图（含动画 PNG / WebP），视频 MP4 / WebM / MOV |
| 大小限制 | 单个文件不超过 200 MB，素材库最多 60 个 |
| 导入方式 | 点「添加背景」选择文件（可多选），或直接把文件拖进主窗口 |
| 设置对象 | 主界面、桌面小组件分别设置；小组件也可以选「跟随主界面」 |
| 显示方式 | 铺满裁剪，或完整显示（空白处用画面的模糊色填充） |
| 遮罩暗度 | 0–70%，背景太亮、文字看不清时调暗 |

- 导入时按文件内容识别真实格式，改了扩展名的文件也能正确识别，不支持的文件会提示原因。
- 同一个文件导入两次会被识别为重复，不会多占空间。
- 素材会复制到应用数据目录，删除或移动原文件不影响使用。
- 视频静音循环播放；窗口隐藏时自动暂停，不占用资源。
- 素材文件丢失或无法播放时，自动退回默认的小狐狸场景。

## 版本与升级

- 新版本安装包可以直接覆盖安装旧版本，**工作设置和自定义背景都会保留**（数据存放在用户目录，不在安装目录里）。
- **Windows**：运行新安装包时会读取已安装的版本号：
  - 版本更新：提示「将从 vX 升级到 vY」，自动安装到原来的位置；
  - 版本相同：询问是否重新安装（修复）；
  - 版本更旧：提示降级风险，需要确认。

  如果程序正在运行，安装时会自动关闭它。卸载也不会删除用户数据。
- **macOS**：把新版本拖进「应用程序」，选择「替换」即可。
- 升级后第一次打开会弹出本次更新内容；「应用」页里可以随时查看版本号和完整更新日志。
- 如果打开了比上次更旧的版本，会提示降级风险。
- 配置文件里新版本才有的字段会原样保留，降级后再升级不会丢数据。

用户数据位置（也可以在「应用 → 打开数据文件夹」里打开）：

- macOS：`~/Library/Application Support/摸鱼小狐/`
- Windows：`%APPDATA%\摸鱼小狐\`

其中 `config.json` 是全部设置，`backgrounds/` 是背景素材。

## 计算口径

| 项目 | 公式 |
| --- | --- |
| 日薪 | 月薪 ÷ 计薪天数 |
| 时薪 | 日薪 ÷ 每日有效工时（扣除午休） |
| 今日已赚 | 今日已工作秒数 × 日薪 ÷ 每日有效工作秒数 |
| 本月累计 | 月薪 × 本月已过工作日（含今天的进度）÷ 本月工作日总数 |
| 发薪日 | 发薪日超过当月天数时，取当月最后一天 |

示例：月薪 10000、9:00–18:00、午休 12–13 点，在 17:40:24 时显示 **¥440.99**、**00:19:36**、**96%**。

## 安装包

| 平台 | 文件 | 大小 | 说明 |
| --- | --- | --- | --- |
| macOS（M1/M2/M3/M4） | `摸鱼小狐-<版本>-mac-苹果芯片.dmg` | 约 103 MB | 2020 年底之后的 Mac 大多是这种，需要 macOS 12 及以上 |
| macOS（Intel） | `摸鱼小狐-<版本>-mac-Intel芯片.dmg` | 约 109 MB | 较老的 Mac。不确定的话看「关于本机」：写着 Apple M 系列就用苹果芯片版 |
| Windows | `摸鱼小狐-<版本>-Windows.exe` | 约 108 MB | 64 位，适用于 Windows 10 / 11，可以选择安装目录 |

**为什么有 100 MB？** 应用本身的代码和图片只有约 250 KB，剩下的都是内置的浏览器内核（Electron = Chromium + Node.js）。所有 Electron 应用（微信开发者工具、VS Code、飞书等）都要带这一份。已经做过的瘦身：

- 删掉 52 种用不到的界面语言包，只保留中文和英文；
- 安装包用最高压缩；
- mac 按芯片分成两个包，不再把两种芯片打进同一个包（原来 213 MB）。

再往下压就得换技术（比如 Tauri 调用系统自带的浏览器内核，包可以小到 10 MB 左右），代价是重写主进程，而且 Windows 和 mac 的显示效果会有差异。

安装包没有购买开发者证书签名，第一次打开时系统会拦截：

- **macOS**：把应用拖进“应用程序”后，右键 → 打开。如果还是打不开，到“系统设置 → 隐私与安全性”里点“仍要打开”。还不行的话，在终端执行
  `xattr -cr /Applications/摸鱼小狐.app`
- **Windows**：SmartScreen 弹窗里点“更多信息 → 仍要运行”。

## 开发

```bash
npm install          # 已配置 npmmirror 国内镜像
npm start            # 本地运行
```

## 打包

```bash
npm run release      # 一键：打 Windows + mac 安装包和源码包，整理到 releases/v<版本>/
npm run dist:win     # 只打 Windows 安装包（macOS / Windows 上都可以打）
npm run dist:mac     # 只打 macOS 安装包（只能在 macOS 上打）
npm run pack:source  # 只打源码包
npm run assets       # 重新生成图标（仅在修改图标设计时需要，需在 macOS 上运行）
```

`dist/<版本>/` 是打包工具的原始输出（英文文件名）；`releases/v<版本>/` 是整理好、可以直接发给别人的文件。

在 macOS 上交叉打 Windows 包不需要 wine：exe 的图标和版本信息由 `scripts/after-pack.js` 用纯 JS 的 resedit 写入。

### 发布新版本

1. 修改 `package.json` 里的 `version`（按 `主.次.修订` 递增）。
2. 在 `main/changelog.js` 最前面加一条更新说明，用户升级后会看到它。
3. 运行 `npm run release`。

`appId`（`com.moyufox.desktop`）不要修改，否则新安装包无法识别并覆盖旧版本。

## 目录结构

```
main/            主进程
  main.js        窗口、小组件、托盘、提醒、版本检测、IPC
  preload.js     contextBridge，渲染进程只能通过 window.moyu 调用
  store.js       配置文件 config.json（分区存储、新字段自动补齐、未知字段保留）
  backgrounds.js 背景素材库：格式识别、去重、缩略图、moyu-bg:// 只读协议（支持 Range）
  focus.js       专注识别：前台软件监听（mac / Windows）、专注 / 摸鱼 / 离开判定与按天统计
  changelog.js   更新日志
src/
  index.html     主界面
  widget.html    桌面小组件
  js/core.js     计算核心（倒计时、收入、休息日、发薪日），主进程和渲染进程共用
  js/scene.js    手绘 SVG 场景和互动
  js/media.js    自定义背景渲染层（图片 / GIF / 视频）
  js/app.js      主界面逻辑
  js/widget.js   小组件逻辑
  css/           样式
assets/          运行时图标（托盘、窗口）
build/           打包图标（icns / ico）、Windows 安装器脚本 installer.nsh
scripts/         图标生成、打包、源码打包脚本
```

## 已知限制

- 不支持跨天的夜班（下班时间必须晚于上班时间）。
- 法定节假日不会自动同步，需要在“节假日 / 调休”里手动添加。
- 视频背景不播放声音。HEVC（H.265）编码的视频在部分 Windows 电脑上可能无法播放，建议使用 H.264 编码的 MP4 或 WebM。
- 没有联网自动更新，需要手动下载新的安装包覆盖安装。
